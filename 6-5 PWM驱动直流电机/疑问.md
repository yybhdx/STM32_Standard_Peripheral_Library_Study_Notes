## 疑问一：仅使用定时器中断与使用输出比较模式在配置上有何区别？

### 💡 核心结论
* **`TIM_TimeBaseInit`（时基配置）**是所有定时器功能的基础，相当于构建了定时器的“心跳”。
* **`TIM_OCInit`（输出比较配置）**是上层建筑，只有当需要在引脚上**自动输出波形（如 PWM）**时才需要配置。

### ⚙️ 两种用法的配置流程对比

```
【用法一：仅使用定时器中断】
RCC时钟开启 ──> TIM时钟源选择 ──> TIM_TimeBaseInit() ──> 开启TIM中断 ──> NVIC配置 ──> TIM_Cmd()使能

【用法二：输出比较（PWM输出）】
RCC时钟开启 ──> TIM时钟源选择 ──> TIM_TimeBaseInit() ──> TIM_OCInit() ──> GPIO(复用推挽) ──> TIM_Cmd()使能
```

### 📊 对比总结

| 对比项 | 仅定时器中断 | 输出比较（PWM输出） |
| :--- | :--- | :--- |
| **时基单元 (`TIM_TimeBaseInit`)** | **✅ 必须配置** (决定中断周期) | **✅ 必须配置** (决定 PWM 频率) |
| **输出比较 (`TIM_OCInit`)** | ❌ 无需配置 | **✅ 必须配置** (决定 PWM 占空比) |
| **GPIO 引脚配置** | ❌ 无需配置引脚 | **✅ 必须配置** (需设为复用推挽输出 `GPIO_Mode_AF_PP`) |
| **中断与 NVIC 配置** | **✅ 必须配置** (需响应中断服务函数) | ❌ 通常不需要 (硬件自动控制引脚，不占用 CPU) |
| **CPU 资源占用** | 较高 (每次定时溢出都需要 CPU 介入处理) | 极低 (一旦配置完成，硬件自动输出波形，零 CPU 损耗) |

## 疑问二：为什么使用输出比较时，对应的引脚必须配置为“复用推挽输出”模式？

### 💡 核心结论
这是为了**将引脚的控制权从“CPU”移交给“定时器外设”**。

### 内部电平控制路径图解

STM32 的 GPIO 引脚背后有两条控制路径，通过引脚的 `GPIO_Mode` 进行选择：

```
                    ┌──────────────────┐
  CPU 软件写入 ───>  │  输出数据寄存器   │──┐
  (GPIO_SetBits)    │     (ODR)        │  │
                    └──────────────────┘  │     ┌─────────┐
                                          ├──>  │ 多路选择 │──→ 物理引脚 (如 PA2)
                    ┌──────────────────┐  │     │  开关    │
  TIM2_OC3 输出 ──>  │  片上外设信号     │──┘     └─────────┘
  (硬件自动)        │  (复用功能)       │
                    └──────────────────┘
```

* **普通推挽输出 (`GPIO_Mode_Out_PP`)**：多路开关指向 **ODR 寄存器**。引脚电平只听 CPU 的（即软件执行代码控制）。
* **复用推挽输出 (`GPIO_Mode_AF_PP`)**：多路开关指向 **片上外设信号**。引脚电平直接由 TIM2 通道 3 的硬件比较器驱动，CPU 的写入失效。

> [!IMPORTANT]
> 如果不配置为复用推挽输出（例如配成了普通推挽输出），定时器产生的 PWM 波形信号将被多路开关挡住，无法输出到外部物理引脚上。

## 疑问三：定时器的 4 个通道是否可以全部开启并用于输出 PWM 波形？

### 💡 核心结论
**完全可以！** 这是一个定时器非常标准且高效的用法（例如用于四轴飞行器或四驱智能小车的电机控制）。

若同时开启同一个定时器（如 TIM2）的 4 个通道输出 PWM，它们具有以下特征：

### 1. 频率必须完全相同
由于 4 个通道**共用同一个时基单元**（共享同一个 `ARR` 自动重装值和 `PSC` 预分频值），因此它们输出的 PWM 信号**频率（周期）是绝对一致的**。

### 2. 占空比可以独立控制
每个通道都拥有自己独立的**捕获/比较寄存器（CCR）**：
* 通道 1 对应 `CCR1` ── 通过 `TIM_SetCompare1()` 修改
* 通道 2 对应 `CCR2` ── 通过 `TIM_SetCompare2()` 修改
* 通道 3 对应 `CCR3` ── 通过 `TIM_SetCompare3()` 修改
* 通道 4 对应 `CCR4` ── 通过 `TIM_SetCompare4()` 修改

你可以为 4 个通道赋予不同的 CCR 值，从而控制 4 个引脚输出不同占空比的波形。

### 3. 输出到不同的物理引脚
以 TIM2 为例，4 个通道分别对应 4 个不同的引脚：
* **TIM2_CH1** ──对应引脚 **PA0**
* **TIM2_CH2** ──对应引脚 **PA1**
* **TIM2_CH3** ──对应引脚 **PA2** (本项目电机驱动使用的通道)
* **TIM2_CH4** ──对应引脚 **PA3**

> [!TIP]
> **形象比喻：**
> 可以把定时器看作一个**“大水泵”**（时基单元），它决定了出水的总压力和总频率；而 4 个通道就像是分流出来的 **4 根独立水管**，每根水管上都有一个**独立的阀门**（CCR），你可以自由调节每个阀门的开度（占空比）来控制每根水管的水流量（电机速度）。

## 疑问四：关于时基单元（PSC/CNT/ARR）与捕获比较寄存器（CCR）的归属关系

### 💡 核心结论
你的理解是 **100% 正确**的。
* **时基单元**（PSC、CNT、ARR）是定时器的“基础心脏”，只负责底层的计数 and 定时，不涉及物理引脚。
* **CCR（捕获/比较寄存器）** 属于“通道单元”，是**输出比较**和**输入捕获**功能的核心，它起到了联通定时器内部计数器与外部物理引脚的桥梁作用。

### 🔍 为什么 CCR 寄存器叫“捕获/比较”？

因为它在不同的工作模式下扮演不同的角色：

#### 1. 输出比较模式 (Output Compare) —— 扮演“目标值”
* **运作机制**：CPU 写入一个数值到 **CCR** 中。当定时器计数器 **CNT** 的值累加到与 **CCR** 相等时，硬件比较器会自动改变输出通道电平状态。
* **主要用途**：产生 PWM 信号调速或调光。

#### 2. 输入捕获模式 (Input Capture) —— 扮演“照相机”
* **运作机制**：当外部引脚（如 PA2）检测到设定的电平跳变（如上升沿）时，硬件会瞬间将当前 **CNT** 的数值复制到 **CCR** 寄存器中，并触发中断通知 CPU 来读取。
* **主要用途**：测量外部信号的频率、脉冲宽度或用于编码器测速。

## 疑问五：定时器在输出 PWM 的同时，还能用来做定时中断吗？

### 💡 核心结论
**完全可以，但中断的触发频率会被强制绑定为 PWM 的输出频率。**

在具体项目开发中，你可以选择以下两种方案：

### 方案一：继续共用当前定时器（如 TIM2）
因为引脚上的 PWM 输出是由**输出比较通道**硬件自动控制的，这并不妨碍**时基单元**在 CNT 达到 ARR 时产生溢出，并触发“更新中断（Update Interrupt）”。
* **优点**：节省硬件定时器资源。
* **限制**：中断频率与 PWM 频率相同。例如本项目中 PWM 为 1kHz，则中断必须是每 1ms 触发一次。
* **典型应用**：在 1ms 定时中断里编写电机的 PID 闭环控制算法。

### 方案二：开启芯片内的其他定时器（如 TIM3）
如果定时任务的频率和 PWM 频率不一致（例如需要 500ms 闪烁一次 LED，或者 100ms 读取一次传感器），或者不想让频繁的 1ms 中断打断 CPU 的其他工作。
* **优点**：两个定时器完全独立，互不干扰，程序逻辑更清晰。
* **支持外设**：STM32F103C8T6 拥有 `TIM1`、`TIM2`、`TIM3`、`TIM4` 共 4 个定时器，资源充足。

## 疑问六：调整比较寄存器 CCR 的值对直流电机的控制起到了什么作用？

### 💡 核心结论
调整 **CCR** 的值，直接控制了直流电机的**旋转速度（转速）**。

### ⚙️ 控制传导链路

```
修改 CCR3 的值 (0~100) 
   │
   ▼
调整 PA2 引脚 PWM 输出的占空比 (Duty Cycle)
   │
   ▼
改变驱动芯片输出给电机的“等效平均电压” (等效电压 = 实际电源电压 × 占空比)
   │
   ▼
控制电机内部电磁力大小 ──> 最终实现电机转速的精确调节
```

* **全速状态**：`CCR = 100` ──> 占空比 $100\%$ ──> 等效电压等于电源电压 ──> 电机最快。
* **减速状态**：`CCR = 50` ──> 占空比 $50\%$ ──> 等效电压减半 ──> 电机中速。
* **停止状态**：`CCR = 0` ──> 占空比 $0\%$ ──> 等效电压为 0V ──> 电机静止。
